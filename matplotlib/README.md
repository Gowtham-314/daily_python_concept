## ✨ Overview

This folder contains concise Jupyter notebooks that introduce basic plotting and visualization techniques using Matplotlib. Examples focus on common plots, styling, and patterns you can use in data exploration and simple reporting.

---

## 📚 What You Will Learn

| | Skill |
|:---:|---|
| 📈 | Create common plot types (line, scatter, bar, histogram) |
| 🎨 | Customize colors, markers, and line styles |
| 🧭 | Label axes, add legends and titles |
| 🗂️ | Save figures to images and adjust figure size |

---

## 🗂️ Files

```
matplotlib/
├── learn_matplotlib.ipynb
├── matplotlib.ipynb
└── README.md
```

- `learn_matplotlib.ipynb`: Guided notebook with step-by-step plotting examples.
- `matplotlib.ipynb`: Short exercises and variations to practice styling and layouts.

---

## ⚙️ Requirements

Install the minimal packages to run these notebooks:

```powershell
pip install jupyterlab notebook matplotlib numpy
```

---

## 🚀 Quick Start

- From the repository root, start Jupyter Lab:

```powershell
jupyter lab
```

- Open `matplotlib/learn_matplotlib.ipynb` and run cells interactively.

---

## 📝 Notes

- Examples assume a working Python environment with Matplotlib installed.
- Figures save to the local folder when examples call `plt.savefig()`.
